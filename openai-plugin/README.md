# SproutMe OpenAI plugin package

Upload `sproutme-plugin.zip` (sibling of this folder) in the OpenAI plugin portal.

Contents live under `sproutme/`:
- `plugin.json` — listing metadata, URLs, review test cases
- `mcp.json` — remote MCP (`streamable-http`)
- `skills/get-started/` — onboarding skill
- `assets/` — logo / composer icons

After upload: connect MCP in the dashboard, complete domain verification, Scan tools, and add a demo recording URL if the form requires it.
